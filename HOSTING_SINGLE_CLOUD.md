# Host on a Single Cloud (Streamlit Community Cloud)

Use these steps to host the FER frontend on one cloud platform: **Streamlit Community Cloud**.

## 1) Push project to GitHub

1. Ensure your repository includes:
   - `streamlit_app.py`
   - `requirements.txt`
   - `emotion_model.h5`
2. Push the latest code to your GitHub repository.

## 2) Sign in to Streamlit Community Cloud

1. Open: https://share.streamlit.io
2. Sign in with your GitHub account.

## 3) Create the app

1. Click **New app**.
2. Select your repository (`chirag-dua123/fer_system`).
3. Branch: choose your deploy branch (for example, `main`).
4. Main file path: `streamlit_app.py`.
5. Click **Deploy**.

## 4) Verify deployment

1. Wait for dependency installation and app startup.
2. Open the app URL generated by Streamlit Cloud.
3. Upload/capture an image and verify emotion predictions are shown.

## 5) Redeploy on updates

1. Push new commits to the configured branch.
2. Streamlit Cloud auto-redeploys the app.

## Notes

- If deployment fails, check the Streamlit Cloud build logs for missing dependencies.
- Keep `emotion_model.h5` in the repository (or load it from cloud storage and update `streamlit_app.py` accordingly).
